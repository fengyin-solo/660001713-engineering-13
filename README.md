# solo-6600017: 天文星图交互式渲染器

## 技术栈
- Vue 3 + TypeScript + Vite + Pinia + Tailwind CSS
- Canvas 2D 天文投影渲染

## 核心特性
1. **赤道坐标投影**：RA/Dec → 地平坐标 (Alt/Az) 实时转换
2. **88 星座渲染**：6 个典型星座（猎户/大熊/仙后/天蝎/天鹅/狮子）+ 连线 + 名称
3. **可回放时间管线**：按固定步长构建帧序列，每帧星体位置本地保存，回放只读不重算；支持两时刻差异对比
4. **时间旅行**：通过日期时间选择器查看任意时刻的星空
5. **天体搜索**：输入星名定位，点击星体显示详细信息
6. **光谱色彩**：O/B/A/F/G/K/M 七种光谱类型对应不同颜色
7. **交互控制**：缩放、纬度调节、星名/连线/网格显示开关

## 启动
```bash
cd frontend && npm install && npm run dev
```

## 可回放时间管线

时间推进（儒略日/恒星时）、赤道→地平投影与归一化坐标是纯函数，集中在
`src/pipeline/`，浏览器运行时与构建校验脚本共用同一份实现：

| 文件 | 职责 |
| --- | --- |
| `src/pipeline/astronomy.ts` | 时间推进（JD/LST）、赤道→地平投影、与视口无关的归一化坐标 |
| `src/pipeline/timePipeline.ts` | 按固定步长逐帧构建、帧存取、顺序回放、两帧逐星差异对比、序列化 |
| `src/pipeline/storage.ts` | `localStorage` 持久化（回放直接读取本地帧） |
| `src/pipeline/verify.ts` | 框架无关的管线校验核心（构建脚本调用） |
| `scripts/verify-pipeline.mjs` | 构建校验入口（esbuild 打包后在 Node 执行） |

设计要点：

- 帧里保存的是**归一化坐标**（屏幕坐标 = 归一化坐标 × 缩放基准尺度 + 画布中心 + 平移），
  因此缩放/平移/窗口尺寸变化不再触发整片星空重算；纬度或星表变化才需要按新的存储键重建。
- 管线存储键包含起止时刻、步长、纬度与星表指纹，参数变化时旧帧不会被错误复用。
- 按时刻取帧 / 顺序回放取不到结果时一律返回明确原因（超出范围、不在步长网格上、帧缺失/错位），
  界面与构建日志都不会静默跳过。

### 构建期回放校验

`npm run build` 会先执行 `npm run verify:pipeline`（prebuild 钩子）：

1. 在固定区间 **2024-03-20 00:00 UTC ~ 2024-03-21 00:00 UTC** 上按 **1 小时**步长
   构建 25 帧管线并落盘到 `frontend/.pipeline-cache/`（文件系统存储）；
2. 重新从磁盘加载（回放走读取路径，不重算），检查帧序连续、时刻对齐、无缺失；
3. 全量 25 帧顺序回放，逐星与「直接推进现算」（`computeFrame`）比对；
4. 在固定时刻 00:00 / 03:00 / 06:00 / 12:00 / 18:00 / 次日 00:00 上重复上述比对。

任何帧缺失、时刻取不到或位置不一致都会打印具体时刻与星体并让构建失败（退出码 1）。
也可单独运行：

```bash
cd frontend
npm run verify:pipeline                 # 使用默认缓存目录
node scripts/verify-pipeline.mjs <目录>  # 指定缓存目录
```

### 浏览器内回放与对比

侧栏「可回放时间管线」选择起止时刻与步长后「构建/载入」：优先读取 localStorage 中
同键管线（直接读帧），缺失时现场构建并保存，两种情况都有日志提示。播放/逐帧/拖动
进度条均只读帧位置；「以此帧为对比基准」会在画布上叠加从基准时刻到当前时刻的
逐星位移向量，并在侧栏按角距离列出移动最明显的星体。
