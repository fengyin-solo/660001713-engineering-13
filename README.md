# solo-6600017: 天文星图交互式渲染器

## 技术栈
- Vue 3 + TypeScript + Vite + Pinia + Tailwind CSS
- Canvas 2D 天文投影渲染

## 核心特性
1. **赤道坐标投影**：RA/Dec → 地平坐标 (Alt/Az) 实时转换
2. **88 星座渲染**：6 个典型星座（猎户/大熊/仙后/天蝎/天鹅/狮子）+ 连线 + 名称
3. **时间旅行**：通过日期时间选择器查看任意时刻的星空
4. **可回放时间管线**：按固定步长把每个时刻的星体位置逐帧本地保存（`public/time-pipeline/`），回放时直接读取不重算；支持逐帧回放一段时间、对比两个时刻的差异
5. **天体搜索**：输入星名定位，点击星体显示详细信息
6. **光谱色彩**：O/B/A/F/G/K/M 七种光谱类型对应不同颜色
7. **交互控制**：缩放、纬度调节、星名/连线/网格显示开关

## 时间管线
- 管线代码在 `frontend/src/pipeline/`：`astronomy.ts`（时间推进/投影纯函数）→ `pipeline.ts`（逐帧构建+回放+对比）→ `storage.ts`（浏览器 localStorage + 预生成帧回退）
- 构建期校验 `npm run verify:pipeline`（已接入 `npm run build`）：
  1. 按固定参数逐帧构建管线并落盘
  2. 全量逐帧回放，校验帧序连续无缺失
  3. 在固定时刻（2024-01-01 00/12Z、01-02 00Z、01-03 00Z）比对"逐帧回放"与"直接推进现算"的星体位置，不一致即构建失败并指出时刻与星体
  4. 管线数据缺失 / 时刻取不到时必须在日志说明原因，不允许静默跳过
- 运行时回放：侧栏"可回放时间管线"面板构建/复用管线后，可播放、逐帧步进、拖动进度条、选择另一帧对比差异；帧数据缺失会在日志面板说明原因

## 启动
```bash
cd frontend && npm install && npm run dev
```

## 构建
```bash
cd frontend && npm run build   # vue-tsc 类型检查 → 时间管线构建与回放校验 → vite build
```
